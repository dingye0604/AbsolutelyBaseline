# AbsolutelyBaseline

**English** | [中文](./README.zh-CN.md)

A calm, warm Obsidian theme made for long reading and writing sessions. Serif note text, soft neutral surfaces, and a single terracotta accent.

## Install

**From Obsidian** — Settings → Appearance → Themes → Manage, search for **AbsolutelyBaseline**, then **Install and use**.

**By hand** — download `manifest.json` and `theme.css` from the [latest release](https://github.com/dingye0604/AbsolutelyBaseline/releases/latest), put both in `<your-vault>/.obsidian/themes/AbsolutelyBaseline/`, and reload Obsidian.

## What it changes

**Warm, low-contrast surfaces.** Off-white `#f9f9f7` in light mode, a soft charcoal `#2d2d2b` in dark, with a terracotta accent (`#cc7d5e`) for links, tags and highlights. Easy to sit in front of for hours.

**Serif note text.** Instrument Serif for note text and headings, your system's sans-serif for the interface, monospace for code. Line height and heading sizes are set for reading, not for fitting as much as possible on screen.

**Code colours that match.** Separate light and dark palettes for syntax highlighting, chosen to stay readable on warm backgrounds instead of the usual cold blue-grey.

Everything else — workspace layouts, callouts, tables, mobile behaviour, every animation — comes from [Baseline](https://github.com/aaaaalexis/obsidian-baseline) untouched. If you like how this theme *behaves*, that is Baseline's doing.

## Optional: other layouts

Install [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) and you can switch between the workspace layouts Baseline ships with — Baseline, Fusion, Cupertino, macOS, Classic and Minimal. The colour and typography stay the same either way.
